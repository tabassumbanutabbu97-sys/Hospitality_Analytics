# Hospitality_Analytics

Project Overview:
This project analyzes hospitality data to generate insights on revenue, bookings, and occupancy using SQL, Excel, Power BI, and Tableau.

Tools Used:
- MySQL (Data Cleaning & KPI Queries)
- Excel (Dashboard & Analysis)
- Power BI (Interactive Dashboard)
- Tableau (Data Visualization)

Key KPIs:
- Total Revenue
- Occupancy Rate
- Cancellation Rate
- Total Bookings
- Utilized Capacity
- Weekday vs Weekend Analysis
- Revenue by State & Hotel
- Class-wise Revenue
- Booking Status (Checked-out, Cancelled, No-show)
- Weekly Trends (Revenue, Bookings, Occupancy)

Project Workflow:

1. Data cleaning using Excel
2. Dashboard creation in Excel, Power BI, and Tableau
3. Designed and implemented SQL queries to extract and analyze hospitality data.


Key Insights:

- Weekend bookings generate higher revenue
- Certain states contribute more to occupancy
- Cancellation rate impacts overall revenue
